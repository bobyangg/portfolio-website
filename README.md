# Bob Yang - personal website

**Live site: [bobyangg.github.io/portfolio-website](https://bobyangg.github.io/portfolio-website/)**

My personal site: a short introduction, where I've worked, projects I've built, and how to reach me.

## About the site

- Light and dark themes. The page follows your system setting by default, and the toggle in the top right remembers your choice.
- Responsive from phone to desktop.
- Fonts are [Newsreader](https://fonts.google.com/specimen/Newsreader) and [Inter](https://fonts.google.com/specimen/Inter), loaded from Google Fonts.

## Running it locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deployment

The site is hosted on GitHub Pages and served from the root of the `main` branch. Pushing to `main` redeploys it, usually within a minute.
